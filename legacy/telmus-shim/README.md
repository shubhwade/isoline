# telmus (superseded by isoline)

Telmus was renamed **Isoline**. This final `telmus` release only installs `isoline` and keeps the
`telmus` command and `import telmus` working. Earlier `telmus` releases and their download history
remain on this project unchanged.

    pip install isoline

New releases are published as `isoline`; see https://pypi.org/project/isoline/.
